⚡ Dynamiczne filtrowanie (JavaScript API)

Wtyczka udostępnia globalną funkcję JavaScript do programatycznej zmiany filtrów bez przeładowania strony:

Funkcja develogicUpdateFilters()

window.develogicUpdateFilters({ pietro: 3, pokoje: 2, promocja: 1 });

Efekt: URL zostanie zaktualizowany i filtry zastosowane automatycznie bez przeładowania strony

Przykład: Przyciski szybkiego dostępu

<button onclick="develogicUpdateFilters({ pietro: 3 })"> Piętro 3 </button> <button onclick="develogicUpdateFilters({ pokoje: 2, promocja: 1 })"> 2-pokojowe w promocji </button> <button onclick="develogicUpdateFilters({ metraz_od: 40, metraz_do: 60 })"> 40-60 m² </button>

Przykład: Reset filtra

// Usuń filtr piętra window.develogicUpdateFilters({ pietro: null }); // Lub ustaw na 'all' window.develogicUpdateFilters({ pietro: 'all' });

Przykład: Integracja z własnym formularzem

document.getElementById('myForm').addEventListener('submit', function(e) { e.preventDefault(); window.develogicUpdateFilters({ pokoje: document.getElementById('rooms').value, pietro: document.getElementById('floor').value, budynek: document.getElementById('building').value }); });
💡 Wskazówka: Funkcja automatycznie aktualizuje URL w pasku przeglądarki (bez przeładowania) i aplikuje filtry. Użytkownicy mogą używać przycisków "wstecz" i "dalej" w przeglądarce!
